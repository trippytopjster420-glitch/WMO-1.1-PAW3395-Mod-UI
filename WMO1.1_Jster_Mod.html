Angle snapping

Hold the left button in the box and draw a slow line that tilts slightly, like a gentle ramp. Draw the same line with angle snapping off and again with it on. Snapping is set to -.The WMO 1.1 has no angle-snapping setting, so this shows how its sensor draws on its own.

LineLengthTiltWobbleLongest level stretchSteps

Without snapping, a tilted line climbs in many small steps and wobbles a little. If snapping works, the same stroke comes out level or nearly level: few or no steps, and a level stretch close to the whole length. Hand-drawn lines that are perfectly level every time mean snapping is active.

The original WMO 1.1 has no settings memory and no setup channel, so there is nothing to send to it. Its polling rate is decided by the PC: the mouse asks to be read every 8 ms (125 Hz), and an overclock tells the PC's USB driver to read it more often. Nothing on the mouse changes, and undoing the overclock puts it straight back.

Check it

Open the Test tab and move the mouse quickly in circles for a few seconds. Highest should come close to the target. If it stays near 125 Hz, the overclock isn't active. If it lands in between, or the pointer stutters, this mouse can't hold that rate: pick one step lower and test again.

The sensor runs at one fixed speed, 400 DPI, and the mouse can't store anything. Everything else about how it feels is set on the PC. This tab works out the numbers and shows where to set them; it doesn't change anything by itself.

Pointer speed in Windows
Pointer speed notch

The 11-notch slider in Mouse Properties, Pointer Options, counted from the left.

Multiplier-
Desktop speed- DPI
Settings app slider- of 20

  1. Open Settings, Bluetooth & devices, Mouse, then Additional mouse settings.
  2. On Pointer Options, set the speed slider to notch 6 and untick Enhance pointer precision. That tick box is Windows' acceleration: with it on, the same hand movement goes a different distance depending on how fast you move.
  3. Press OK. Games that read raw input, which is most shooters, ignore both settings. They change the desktop and games that use the Windows pointer.
Pointer speed on Linux

Turn acceleration off so the pointer goes the same distance however fast you move. GNOME: Settings, Mouse & Touchpad, turn off Mouse Acceleration, or run:

gsettings set org.gnome.desktop.peripherals.mouse accel-profile 'flat'

KDE Plasma: System Settings, Mouse, turn pointer acceleration off (the flat profile).

Buttons and clicks

The mouse can't store a remap, so remapping is done by software on the PC: X-Mouse Button Control on Windows, or input-remapper on Linux.

An old WMO 1.1 can start double-clicking as its switches wear. It has no debounce setting, so the fix is cleaning or replacing the switch. The Test tab's click check shows whether it's happening.
